# 🍕 LaCrosta – Pizza Delivery System

LaCrosta is a full-stack MERN-based Pizza Delivery System that allows users to build and customize pizzas, place online orders, make secure payments, and track their orders. The application also provides a comprehensive admin dashboard for managing pizzas, inventory, and customer orders.

---

## 🚀 Features

### 👤 User Features
- User Registration & Login
- Email Verification
- Forgot & Reset Password
- JWT Authentication
- Build Your Own Pizza
- Custom Pizza Bases, Sauces, Cheeses, Toppings & Veggies
- Shopping Cart
- Address Management
- Razorpay Payment Integration
- Order Placement
- Order History
- Profile Management

### 🛠️ Admin Features
- Admin Dashboard
- Manage Pizza Menu
- Manage Inventory
- Manage Ingredients
- Manage Orders
- Low Stock Notifications
- User Management

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/pizza-delivery-system.git
```

### Navigate to the Project

```bash
cd pizza-delivery-system
```

### Install Dependencies

#### Frontend

```bash
cd client
npm install
```

#### Backend

```bash
cd ../server
npm install
```

---

## ▶️ Run the Application

### Backend

```bash
npm run dev
```

### Frontend

```bash
cd ../client
npm run dev
```

---

## 🔐 Environment Variables

Create a `.env` file inside the **server** folder and configure the following variables:

```env
PORT=

MONGO_URI=

JWT_SECRET=

CLIENT_URL=

MAIL_HOST=
MAIL_PORT=
MAIL_USER=
MAIL_PASS=

RAZORPAY_KEY_ID=
RAZORPAY_KEY_SECRET=
```
